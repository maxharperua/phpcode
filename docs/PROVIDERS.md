# Провайдеры агента

В панели агента нажмите кнопку с именем текущего провайдера справа сверху. В настройках подключения выберите **BotHub** или **polza.ai**, сохраните API-ключ и выберите модель. Можно загрузить каталог либо ввести ID вручную.

Провайдер сохраняется для каждого чата. При переключении восстанавливается последняя выбранная модель соответствующего сервиса, а бюджет контекста возвращается к автоматическому. Каталоги моделей хранятся отдельно; запоздавший ответ одного каталога не заменяет список другого провайдера. Старые чаты и существующий ключ BotHub продолжают работать без перенастройки.

Ключи находятся в защищённом хранилище Code OSS под разными именами. Их нет в настройках, истории или экспортируемом состоянии проекта. Удаление ключа одного сервиса не затрагивает другой. Если ключ выбранного сервиса отсутствует, запрос не отправляется: автоматического переключения на другой сервис нет. Во время выполнения задачи переключатель провайдера недоступен.

Используются фиксированные HTTPS API:

- BotHub: `https://openai.bothub.chat/v1`.
- polza.ai: `https://polza.ai/api/v1`.

Запросы идут из main-процесса. Произвольные URL из renderer не принимаются; перенаправления запрещены. Для polza.ai каталог `/models?type=chat` публичный, без отправки ключа. Для генерации используется ключ polza.ai и `/chat/completions`. Поддерживаются SSE, инструменты, субагенты, суммаризация и существующие Claude cache-метки. Субагенты и суммаризация наследуют провайдера и модель текущей задачи.

Смена провайдера в существующем чате означает, что дальнейшие запросы с сохранённым контекстом чата отправляются выбранному сервису; это также указано в интерфейсе подключения.

API-схема, каталог и кеширование сверены с официальной документацией: [Chat Completions](https://github.com/polza-ai/docs/blob/main/api-reference/chat/completions.mdx), [Models](https://github.com/polza-ai/docs/blob/main/api-reference/models/list.mdx), [Caching](https://github.com/polza-ai/docs/blob/main/osobennosti/caching.mdx).

## Проверка

`agentProvider/test/provider.test.ts` проверяет маршрутизацию, авторизацию, публичный каталог и отклонение неизвестного провайдера, а также изоляцию окон и отмену запросов.

`PHPCODE_PROVIDER_SMOKE=1 PHPCODE_PACKAGED_EXECUTABLE=/absolute/path/to/phpcode node verify-agent.cjs` использует отдельный профиль и подставные ответы HTTP: переключение провайдера, сохранение моделей, раздельные ключи, стриминг, инструменты, субагенты, кеш-метки, суммаризацию, запоздавший каталог и восстановление после перезапуска. Реальные запросы генерации и баланс не используются.
