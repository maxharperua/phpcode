# phpcode v0.1.1

## Что изменилось

- Выбор провайдера агента: BotHub и polza.ai. Ключи и выбранные модели хранятся отдельно; существующие чаты продолжают работать с BotHub.
- Субагенты для независимых задач: до трёх одновременно, собственный контекст, отображение хода работы и результатов под сворачиваемым блоком.
- Индикаторы работы агента и субагентов, время выполнения и восстановление истории после перезапуска.
- Исправлено зависание команд Git в скрытом терминале агента из-за интерактивного pager. Настройки пользовательских терминалов не меняются.
- Новая оригинальная иконка приложения для Windows, Linux и macOS.
- Новая базовая тема Marsh: тёмно-зелёные поверхности и приглушённый болотный акцент. Старая тема phpcode Dracula автоматически заменяется на Marsh.
- Компактное поле ввода чата, мягкий контур фокуса, название модели при наведении. Неиспользуемая кнопка аккаунта удалена из интерфейса.
- Diff и отмена правок представлены иконками с подсказками. У ответов агента при наведении появляются копирование и дата/время.

## Установка

- Windows x64: пользовательский установщик `.exe` или переносимый `.zip`.
- Linux x64: пакет `.deb` или переносимый `.tar.gz`.
- macOS Apple Silicon: установочный `.dmg`.

Сборки основаны на Code OSS 1.146.0. Контрольные суммы приложены в `SHA256SUMS`, сведения об исходниках каждой сборки — в `builds.json`.

Это предварительный релиз. Пакеты пока без собственной цифровой подписи и notarization.
