# Субагенты phpcode

`run_subagent` — инструмент основного агента в режиме Agent. Модель выбирает делегирование сама; пользователь также может попросить её запустить несколько субагентов. Например: «Параллельно изучи маршруты и работу с БД двумя субагентами, затем предложи исправление».

Каждый работник начинает с отдельного контекста: системные инструкции, политика окружения и конкретная задача от родителя. Переписка родителя не копируется. Чтение, промежуточные ответы и команды остаются внутри карточки; основной агент получает финальный отчёт до 8000 символов и явный статус. Суммаризация выполняется отдельно для дочернего контекста. API-запросы идут через существующий BotHub transport и учитываются в общей статистике токенов чата; модель и кеширование наследуются от родителя.

Встроенные роли:

- `explore`: индекс, поиск, список файлов, чтение; без правок и терминала.
- `shell`: чтение и терминал; без инструмента правок.
- `general`: чтение, предложения правок и терминал.

До трёх работников выполняются параллельно, до восьми запусков за один ход родителя. Каждый получает до 40 шагов. Вложенная делегация недоступна. Основной агент ожидает завершения группы и продолжает исходную задачу. Фоновые независимые задачи после завершения родителя и пользовательские определения работников пока не реализованы.

Рабочая папка, удалённый контейнер и режим подтверждений остаются теми же. Команды и сохранения сериализованы, поэтому параллельные работники не заменяют чужое ожидающее разрешение. Изменённый другим работником файл нельзя перезаписать без согласования; родитель должен перечитать файл после правки субагента. Общая файловая система не является отдельным worktree или sandbox shell: задачи с изменениями должны иметь разные области файлов.

«Остановить» отменяет весь текущий запуск, включая дочерние запросы и команды. Неудача одного работника возвращается родителю как неудача, без ложного сообщения об успешной работе. Карточки сохраняют результаты и статус после перезапуска; незавершённые становятся остановленными.

Под свёрнутыми «Действиями» видны анимация, текущая фаза, число активных субагентов и прошедшее время. Анимация работает до первого ответа модели и между вызовами инструментов. Ожидание подтверждения подписано отдельно. Раскрытие карточек сохраняется при стриминге; настройка уменьшения движения отключает вращение.

## Проверки

`node scripts/test-agent.cjs` запускает 54 теста чистой логики без загрузки Code OSS. Команда включена в `pnpm test`. Проверены изоляция контекстов, одновременный старт, ограничения параллелизма и числа запусков, запрет вложенной делегации и правок Explore, обработка ошибок и общий abort.

`PHPCODE_SUBAGENT_SMOKE=1 PHPCODE_PACKAGED_EXECUTABLE=/absolute/path/to/phpcode node verify-agent.cjs` проверяет готовую сборку через отдельный профиль с подставным HTTP-ответом BotHub. Реальный API не вызывается. Сценарий проверяет вложенные карточки, ожидание модели, сохранение раскрытия, очередь разрешений и отказ команды, конкурирующие правки, устаревшее предложение родителя, общую остановку и историю после перезапуска. `PHPCODE_DEV_EXECUTABLE` позволяет выбрать существующий dev Electron для проверки дерева исходников.
