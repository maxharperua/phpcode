# phpcode: согласованный состав продукта

Основа: полноценный форк Code OSS. Прототип `forge-desktop` на Monaco остаётся экспериментом и не считается целевой архитектурой. Приложение устанавливается самостоятельно, имеет собственное имя phpcode, палитру Dracula, дерево проекта в духе PhpStorm и единый интерфейс встроенных функций. Настройка пользовательских расширений сохраняется, но агент и БД поставляются вместе с продуктом.

## Сохраняем из редактора

- Вкладки открытых файлов, закрепление, предпросмотр, разделение редактора на области, восстановление несохранённых документов.
- Мультикурсор, сворачивание кода, миникарта, breadcrumbs, сравнение файлов, плавная прокрутка редактора и дерева.
- Глобальный поиск и замена, быстрый поиск файлов и символов, определения и использования, переименование символов и история переходов.
- Git: изменения, ветки, сравнения, конфликты. Несколько терминалов.
- API расширений VS Code, установка VSIX, пользовательские настройки и горячие клавиши, settings.json/keybindings.json, настройки папки .vscode.

## Не включаем в пользовательский интерфейс

Отладчик, точки останова, Xdebug, панель ошибок (Problems), задачи запуска. Внутренние API, необходимые для совместимости расширений, не удаляются автоматически. Подсветка ошибок в редакторе, анализ кода и форматирование остаются; панель Problems для них не требуется.

## Проекты и удалённая работа

Один проект в одном рабочем окне; multi-root workspace не входит в требования. Нужны Remote SSH, devcontainer.json, Docker Compose, подключение к существующим контейнерам и удалённое исполнение языковых инструментов. Воспроизведение этих сценариев должно проверяться на реальных SSH/Docker окружениях. Microsoft Remote Development не является автоматически частью исходников Code OSS; способ реализации и состав распространяемых компонентов проверяются отдельно.

## PHP

Автодополнение и анализ, Composer, PHPUnit и Pest, PHPStan и Psalm, форматирование, Laravel и Symfony, Blade и Twig. Xdebug исключён пользователем отдельно. Требуются как локальные, так и контейнерные PHP-проекты; наличие PHP/Composer/анализаторов определяется для выбранного окружения, а не предполагается на машине пользователя.

## Наши встроенные функции

Чат агента с BotHub как первым провайдером, отдельные сессии, сохранённая история и восстановление закрытых чатов. Несколько подключений SQLite/PostgreSQL/MySQL, навигация по структуре и данным через UI, SQL-редактор. Всё размещается в общей оболочке редактора. Дизайн уточняется далее.

## Совместимость и проверка результата

Совместимость API не означает работоспособность любого расширения Microsoft Marketplace. Для каталога выбран Open VSX и локальная установка VSIX; для конкретных обязательных PHP/remote расширений нужны отдельные проверки доступности, лицензии и совместимости.

Первый этап перехода завершён только после сборки и запуска Code OSS под именем phpcode и проверки вкладок, восстановления документов, Git, нескольких терминалов, поиска, установки тестового VSIX и настроек .vscode. Ни исходный клон, ни старый DMG на Monaco не считаются выполнением этого этапа.
