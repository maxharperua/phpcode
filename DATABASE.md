# Встроенный клиент баз данных phpcode

Раздел **Базы данных** в левой панели и кнопка **+** открывают форму подключения: название, MySQL/MariaDB или PostgreSQL, хост, порт, пользователь, пароль и имя БД. Можно сохранять множество независимых подключений, проверять соединение, менять параметры и удалять профиль через контекстное меню. Метаданные хранятся в профиле IDE, пароль — отдельно в `ExtensionContext.secrets`; он не возвращается в webview при редактировании. Пустое поле пароля существующего профиля сохраняет прежний пароль; флажок «Использовать пустой пароль» явно очищает его. TLS использует проверку сертификата сервера.

Подключение раскрывается в дерево схем и таблиц. Таблица открывается отдельной вкладкой редактора: 200 строк на страницу, структура колонок, первичные ключи, типы, NULL и генерируемые поля. В таблице с первичным ключом можно изменить ячейки, добавить или удалить строки, затем сохранить весь набор правок одной транзакцией. Правый клик или Alt+Backspace задают SQL NULL; пустая строка остаётся пустой строкой. В новой строке нетронутые поля используют серверный DEFAULT. В MySQL/MariaDB транзакционный откат требует движка InnoDB. Сравнение исходного значения защищает изменяемые ячейки от незаметного затирания чужих правок; конфликт откатывает весь набор изменений. Таблицы без PK и представления доступны для просмотра и через SQL. Бинарные и большие ячейки в UI не редактируются.

Команда **phpcode: Новый SQL-скрипт** создаёт обычный документ SQL с подсветкой, редактированием и сохранением в файл. Также можно открыть существующий `.sql`. Кнопка запуска в заголовке редактора, **⌘Enter** на macOS или **Ctrl+Enter** выполняют выделенный фрагмент либо весь документ. Подключение выбирается перед первым запуском и доступно в строке состояния. Несколько операторов возвращают отдельные наборы результатов в нижнюю панель **Результаты SQL**. На один набор показывается до 1000 строк; общий результат ограничен 5000 строками / 4 МБ. Просмотр таблиц и SQL не отправляют данные в LLM.

Один открытый SQL-документ использует одну сессию подключения: `BEGIN` / `COMMIT` / `ROLLBACK` работают между запусками. Скрипт выполняется как написан, без автоматической транзакции для всех операторов; уже выполненные команды могут остаться применёнными при ошибке или отмене. **Остановить** закрывает соединение. Неактивный документ сохраняет свою сессию до закрытия документа, смены подключения либо закрытия IDE. Тайм-аут операции — 65 секунд. Запросы выполняются в отдельном worker, чтобы не блокировать интерфейс; отображение ячеек использует DOM `textContent`, SQL-результат не интерпретируется как HTML.

Это собственный встроенный компонент продукта `phpcode.database`, поставляемый вместе с приложением; пользователю не нужно устанавливать клиент из каталога расширений. При локальном проекте подключения используют сеть компьютера; в Dev Container компонент запускается в удалённом extension host и использует сеть контейнера (например, хост `db`, порт `3306`). Профили подключений и секреты принадлежат соответствующей среде: сохранённые на компьютере подключения автоматически в контейнер не копируются.

Сейчас поддерживаются MySQL/MariaDB и PostgreSQL. SQLite, SSH-туннели, импорт дампов с клиентскими директивами `DELIMITER`/`\copy`, произвольные сертификаты CA и визуальное изменение структуры таблиц пока не реализованы. DDL можно выполнять через SQL.

Перед первым применением выполните из `phpcode-product`: `./run.sh pnpm --dir "$PWD/database-runtime" install --frozen-lockfile`. Сборка: `database-runtime/package.json` и lockfile закрепляют mysql2 3.24.6 и pg 8.23.1. `apply-database.cjs` собирает переносимые JS-драйверы, включает лицензии зависимостей и копирует компонент в Code OSS. `package-container-server.cjs` включает его в серверы обеих архитектур. Интерфейс использует токены темы; строки вынесены в bundle локализации.

Проверки: `database/database.test.cjs` выполняет реальные операции в отдельных тестовых MariaDB/PostgreSQL; `verify-database.cjs` управляет упакованным приложением и проверяет форму, сохранение нескольких подключений, редактирование данных, структуру, запуск SQL-файла и восстановление после перезапуска. Тестовые БД — одноразовые контейнеры `phpcode-db-test-mysql` и `phpcode-db-test-postgres` без пользовательских данных.

При открытии доверенного проекта компонент автоматически читает корневой `.env` и создаёт подключение из `DB_CONNECTION`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` или `DB_URL` / `DATABASE_URL`. Пароль хранится только в SecretStorage. Поддерживаются кавычки, комментарии, CRLF, пустой пароль и ссылки `${NAME}` на переменные того же файла; одинарные кавычки сохраняют буквальное значение. Содержимое не исполняется как shell. Автоимпорт не меняет существующие профили и не создаёт дубликаты; команда «phpcode: Импортировать Подключение из .env» повторно читает файл и обновляет тот же профиль. Удалённый пользователем импортированный профиль автоматически не восстанавливается; его можно вернуть явным импортом. В Dev Container файл читается из удалённого проекта, а `db` остаётся внутренним Docker-хостом. `.env.example` автоматически не импортируется.

Редактор таблиц r11 использует компактную полосу иконок с подсказками и короткую строку состояния; заголовок вкладки остаётся в стандартной панели редактора. Структура и справка раскрываются по иконке. Нажатие на заголовок колонки переключает ASC → DESC → исходный порядок. Поиск (Enter или значок лупы) выполняется SQL-запросом по всей таблице, по всем текстовым/числовым колонкам либо выбранной колонке. Символы `%`, `_`, `!` экранируются для буквального поиска; значения передаются параметрами. Поиск и сортировка сохраняются между страницами и после сохранения изменений. Изменённые ячейки нужно сохранить или отменить перед сменой выборки. Ctrl/Cmd+F внутри таблицы фокусирует поле поиска. Индикатор стрелки и `aria-sort` отражают направление сортировки.
